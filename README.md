# 🎬 Netflix-Inspired Web Application — Database Systems

A Netflix-inspired web application developed as a Database Systems university project. The project combines a streaming-platform-style interface with forms and database-related functionality for managing media,
profiles, and subscription information.

## 📌 About the Project

The application recreates selected Netflix-style pages, including a home page, registration form, subscription plans, payment form, and movie management interface.
The HTML pages reference PHP handlers and display pages intended to connect the interface with backend processing and database operations.

## ✨ Features

- 🏠 Home page with featured content and movie categories
- 👤 Profile registration interface
- 🎬 Movie and media entry form
- 💳 Subscription plans and payment form interface
- 📋 Navigation for movies, profiles, and payments
- 🗄️ PHP integration points for database-related operations
